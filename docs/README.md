# kiriya documentation

kiriya is one command-line toolbox for everyday developer work that behaves the same on
Windows, Linux and macOS.

## Use kiriya

| Page | What it covers |
|---|---|
| [Getting started](getting-started.md) | Install kiriya, check your machine, and run your first commands |
| [Usage](usage.md) | What every command shares: help, global options, output, JSON, exit codes, safety, paths and globs, configuration |
| [Modules](modules/README.md) | Every module, each with a guide and a reference of all its commands |
